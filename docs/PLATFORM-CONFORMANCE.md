# Integral Platform Systems — GoreeCloud Markdown

**Status:** Evaluation required — none of these systems is claimed integrated, conformant, or production-accepted by the initial source scaffold.

Current nine-system model (v3.0): Manager, Privacy Shield, Wardveil Security, Everkeep, Glaze, Mesh, Identity, GoreeCloud Policy, and GoreeCloud Observability. GoreeCloud Sync is separately governed, not a tenth system.

| System | Applicability to Markdown | Current evidence/status |
| --- | --- | --- |
| GoreeCloud Manager | Evaluate application lifecycle, managed configuration, updates | Not evaluated |
| Privacy Shield | Local document handling, consent, retention, any future telemetry | Not evaluated |
| Wardveil Security | Files, link handling, dependencies, build/release hardening | Not evaluated |
| Everkeep | Local drafts, recovery, version protection and restore | Not evaluated |
| Glaze | Native Compose mappings, accessibility, layout, motion, tokens | Not evaluated |
| GoreeCloud Mesh | Optional documented capability discovery/contracts | Not evaluated |
| GoreeCloud Identity | Determine whether account-less local editing is non-applicable and when optional identity is required | Not evaluated |
| GoreeCloud Policy | Decisions, ownership and enforcement at approved boundaries | Not evaluated |
| GoreeCloud Observability | Privacy-minimized operation, performance and health evidence | Not evaluated |

No blanket claim of non-applicability. Each row requires an approved contract/version, justified applicability, implemented contract when applicable, current source identity, validation evidence and governed acceptance.

The existing Glaze repository has a Stable 1.7.0 baseline and a separate 1.7.1 development track. The UI here is *Glaze-inspired only* until approved native mapping and evidence are completed.
